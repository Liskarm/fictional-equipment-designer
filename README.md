# Fictional Equipment Designer

一个用于虚构世界观创作的 Codex Skill，面向小说、游戏、动画、概念设计、COS 道具概念和世界观设定集。

它可以设计、修订和审查虚构武器、护甲、工具、载具、遗物、魔法装置及装备家族，重点检查装备的存在必要性、独特定位、能力代价、操作流程、资源与维护、反制手段、阵营风格、世界影响和正史一致性。

使用后可获得结构清晰的快速概念、完整装备档案、变体谱系、视觉简报、世界影响分析或正史条目，让装备不只是“看起来很酷”，而是成为能够被生产、使用、反制并真正影响世界的设定组成部分。

本 Skill 仅用于虚构创作、游戏系统、视觉开发和非功能性道具概念，不提供现实武器制造或改装指导。

## English

A Codex Skill for fictional worldbuilding across novels, games, animation, concept design, cosplay prop concepts, and world bibles.

It designs, revises, and audits fictional weapons, armor, tools, vehicles, artifacts, magical devices, and equipment families. Its reviews focus on why an item needs to exist, what makes its role distinct, what its capabilities cost, how it is operated and maintained, how it can be countered, whether it fits its faction, how it affects the wider world, and whether it remains consistent with canon.

The Skill can produce structured rapid concepts, full equipment dossiers, variant lineages, visual briefs, world-impact analyses, and canon entries. The goal is to make equipment more than something that merely looks cool: it should be producible, usable, maintainable, counterable, and meaningfully integrated into the setting.

This Skill is intended only for fictional creation, game systems, visual development, and clearly nonfunctional prop concepts. It does not provide guidance for constructing or modifying real-world weapons.
